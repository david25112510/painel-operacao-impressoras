# Histórico de alterações

Este arquivo registra mudanças relevantes por versão. O projeto ainda não iniciou uma série de releases públicos.

## Em desenvolvimento

- Painel operacional para Windows com ilustrações, estado, contadores, produção diária e toner.
- Coleta central SNMP v1/v2c, histórico, alertas, usuários, relatórios CSV e backups.
- Inicialização sem impressoras e sem comunidade SNMP pré-configuradas.
- Cliente trata dias sem produção sem interromper o painel.
- Serviço fecha dispatcher pela API `close()` do PySNMP 7.
