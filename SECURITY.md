# Segurança

Leia [Segurança e privacidade](docs/SEGURANCA.md) antes de instalar. Em resumo: mantenha o serviço somente na rede privada, não publique credenciais/dados operacionais e use comunidades SNMP somente de leitura.

Para relatar vulnerabilidade, não abra uma issue pública com detalhes exploráveis. Entre em contato com o mantenedor pelo perfil GitHub e solicite um canal privado. Não envie comunidades, fingerprints, bancos, certificados, chaves ou dados de impressoras.
