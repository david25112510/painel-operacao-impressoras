# Suporte

Antes de abrir uma issue, consulte [Solução de problemas](docs/SOLUCAO-DE-PROBLEMAS.md) e procure issues existentes.

Ao relatar falha, inclua versão do Windows e Python, passos para reproduzir, componente afetado (cliente/servidor), versão SNMP e mensagem de erro sanitizada. Use endereços fictícios nos exemplos.

Não publique endereço real de impressora, comunidade SNMP, URL interna, fingerprint, nome de usuário, exportação, banco SQLite, foto ou certificado. Problemas de segurança devem ser enviados em privado conforme [SECURITY.md](SECURITY.md), não em issue pública.
